# مشروع عجلة الجوائز — نسخة أولية قابلة للنشر

## المحتويات
- واجهة عربية متجاوبة وعجلة متحركة.
- خادم يحدد النتيجة ويسجلها مع رقم مطالبة فريد.
- منع تكرار المشاركة بحسب رقم الهاتف المدخل.
- نقطة بيانات للمشرف: `GET /api/admin/entries` مع الترويسة `x-admin-token`.

## تحذير مهم قبل مسابقة حقيقية
هذه نقطة بداية تقنية وليست إطلاقًا جاهزًا لمسابقة عامة:
1. **التحقق من ملكية الهاتف غير مفعّل**. أضف رمز تحقق OTP عبر مزوّد موثوق قبل الإطلاق؛ إدخال رقم وحده لا يمنع انتحال أرقام الآخرين أو تعدد الشرائح.
2. تحقق من قانونية المسابقة في الأردن ومن التصاريح والشروط اللازمة مع مختص محلي قبل الإعلان.
3. تأكد من توفر الجوائز وتمويلها، وانشر قواعد الأهلية والتواريخ واحتمالات الفوز وآلية تسليم الجوائز وسياسة الخصوصية.
4. الأوزان في `server.js` نموذجية فقط: 1 لكل جائزة رئيسية و6 لـ«حظ أوفر». عدّلها وفق شروط المسابقة الفعلية.
5. استخدم تخزينًا دائمًا لقاعدة SQLite. لا تستخدم قرصًا مؤقتًا لأن البيانات قد تضيع عند إعادة التشغيل.
6. احمِ لوحة المشرف برمز قوي وسري، ولا تضعه في الواجهة العامة.

## النشر على Render
1. فك ضغط الملف وارفع المشروع إلى مستودع GitHub.
2. في Render اختر **New + → Web Service** واربط المستودع.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. أضف متغيرات البيئة:
   - `ADMIN_TOKEN`: رمز قوي عشوائي.
   - `CONTEST_TITLE`: اسم المسابقة.
   - `DB_PATH`: `/var/data/contest.sqlite`
6. أضف Persistent Disk واربطه على `/var/data`.
7. انشر الخدمة؛ ستمنحك Render رابطًا عامًا من نوع `https://اسم-الخدمة.onrender.com`.
8. اختبر منع التكرار والنتيجة وتسجيل المطالبات قبل مشاركة الرابط.

## لوحة المشرف
افتح `https://YOUR-SERVICE-URL/api/admin/entries` مع HTTP header:
`x-admin-token: YOUR_ADMIN_TOKEN`

هذه النسخة لا تتضمن تسجيل دخول متكاملًا للمشرف ولا خدمة OTP، ولا ينبغي إطلاقها للعامة كمسابقة حقيقية قبل استكمال الحماية والمراجعة القانونية.
